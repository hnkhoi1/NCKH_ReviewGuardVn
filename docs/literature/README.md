# Literature notes

The structured literature review for ReviewGuard VN lives in this folder.

Suggested files:

- `literature_review.md` — written summary (English, for submission)
- `paper_table.csv` — one row per paper: citation, year, task, data, method, metrics/results, limitations, relevance

Reading order used so far:

1. Opinion spam and fake reviews: Jindal & Liu (2008), Ott et al. (2011)
2. Group / network approaches: Mukherjee et al. (2012), Rayana & Akoglu (2015)
3. Machine-generated fake reviews: Salminen et al. (2022)
4. Vietnamese resources and language models: ViSpamReviews, PhoBERT, XLM-R
5. Methods toolkit: Sentence-BERT, HDBSCAN, Isolation Forest, Kleinberg burst detection, Louvain, SHAP, LIME
